#### 1.3.1 Units of Memory

- Computers fundamentally understand and store information using **binary digits** (0s and 1s).
- **Bit**: The smallest unit of digital information, representing either a 0 or a 1.
- **Nibble**: A group of 4 bits.
- **Byte**: A group of 8 bits. This is the smallest unit that can typically represent a single character (like a letter or number).
- Larger memory units are formed by combining bytes:

| Unit             | Description                                     |
| :--------------- | :---------------------------------------------- |
| **KB (Kilobyte)** | $1 \text{ KB} = 1024 \text{ Bytes}$             |
| **MB (Megabyte)** | $1 \text{ MB} = 1024 \text{ KB}$               |
| **GB (Gigabyte)** | $1 \text{ GB} = 1024 \text{ MB}$               |
| **TB (Terabyte)** | $1 \text{ TB} = 1024 \text{ GB}$               |
| **PB (Petabyte)** | $1 \text{ PB} = 1024 \text{ TB}$               |
| **EB (Exabyte)** | $1 \text{ EB} = 1024 \text{ PB}$               |
| **ZB (Zettabyte)** | $1 \text{ ZB} = 1024 \text{ EB}$               |
| **YB (Yottabyte)** | $1 \text{ YB} = 1024 \text{ ZB}$               |
