#### 1.6.1 Checking the Dimensional Consistency of Equations
- **Principle of Homogeneity of Dimensions:** For an equation to be dimensionally correct, the dimensions of all terms on both sides of the equation must be the same. If they are not, the equation is definitely wrong.
- **How it works:**
    - If you are deriving an expression for length, after simplifying all dimensions, the final dimension must be [L].
    - If deriving an equation for speed, the dimensions on both sides must simplify to $[L T^{-1}]$.
- **Limitations of Dimensional Consistency:**
    - **Does not guarantee correctness:** A dimensionally consistent equation is not necessarily the perfectly correct equation. For example, dimensionless constants (like 1/2 or $2\pi$) cannot be determined using dimensional analysis.
    - **Dimensionless Quantities:** Arguments of special functions (trigonometric, logarithmic, exponential) must be dimensionless. Pure numbers, ratios of similar physical quantities (like angle = length/length, or refractive index = speed/speed), have no dimensions.

- **Example: Checking the Equation of Motion**
    - Equation: $x = x_0 + v_0 t + (1/2) a t^2$
    - Where: $x$ = final position, $x_0$ = initial position, $v_0$ = initial velocity, $t$ = time, $a$ = acceleration.
    - Let's check dimensions for each term:
        - $[x] = [L]$
        - $[x_0] = [L]$
        - $[v_0 t] = [L T^{-1}] [T] = [L]$
        - $[(1/2) a t^2] = [L T^{-2}] [T^2] = [L]$
    - **Conclusion:** Since every term on both sides has the dimension of length [L], the equation is dimensionally correct.
    - **Important Note:** If an equation fails this test, it's definitely wrong. But if it passes, it's not necessarily correct (e.g., $x = x_0 + v_0 t + a t^2$ would also be dimensionally correct, but the factor of 1/2 is missing).

**Example 1.3: Checking Energy Equation**
- Equation: $\frac{1}{2}mv^2 = mgh$
- LHS: Dimensions of $\frac{1}{2}mv^2$
    - Dimensions of mass [m] = [M]
    - Dimensions of velocity [v] = $[L T^{-1}]$
    - Dimensions of $v^2$ = $[L T^{-1}]^2 = [L^2 T^{-2}]$
    - Dimensions of LHS = $[M] [L^2 T^{-2}] = [M L^2 T^{-2}]$
- RHS: Dimensions of $mgh$
    - Dimensions of mass [m] = [M]
    - Dimensions of acceleration due to gravity [g] = $[L T^{-2}]$ (same as acceleration)
    - Dimensions of height [h] = [L]
    - Dimensions of RHS = $[M] [L T^{-2}] [L] = [M L^2 T^{-2}]$
- **Conclusion:** Since the dimensions of LHS and RHS are the same ($[M L^2 T^{-2}]$), the equation is dimensionally correct.

**Example 1.4: Identifying Incorrect Kinetic Energy Formulae**
- SI unit of Energy (K) is J = $kg~m^2~s^{-2}$, so dimensions of Energy are $[M L^2 T^{-2}]$.
- Let's check the dimensions of the given formulas:
    - (a) $K = m^2 v^3$
        - Dimensions = $[M]^2 [L T^{-1}]^3 = [M^2 L^3 T^{-3}]$
        - This does not match $[M L^2 T^{-2}]$, so (a) is ruled out.
    - (b) $K = (1/2)mv^2$
        - Dimensions = $[M] [L T^{-1}]^2 = [M L^2 T^{-2}]$
        - This matches, so (b) *could* be correct.
    - (c) $K = ma$
        - Dimensions = $[M] [L T^{-2}] = [M L T^{-2}]$ (This is Force)
        - This does not match, so (c) is ruled out.
    - (d) $K = (3/16)mv^2$
        - Dimensions = $[M] [L T^{-1}]^2 = [M L^2 T^{-2}]$
        - This matches, so (d) *could* be correct.
    - (e) $K = (1/2)mv^2 + ma$
        - This involves adding two quantities with different dimensions ($[M L^2 T^{-2}]$ and $[M L T^{-2}]$). This violates the principle that only quantities with the same physical dimensions can be added or subtracted.
        - So, (e) is ruled out.
- **Conclusion:** Formulas (a), (c), and (e) are ruled out based on dimensional arguments. Dimensional analysis cannot distinguish between (b) and (d) because both are dimensionally correct; for that, one needs the actual physics definition.
