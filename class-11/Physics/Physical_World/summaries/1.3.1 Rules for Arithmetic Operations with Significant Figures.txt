### 1.3.1 Rules for Arithmetic Operations with Significant Figures
- When performing calculations with measured values, the result's precision cannot be greater than the least precise input measurement.
- **Rule 1: Multiplication or Division**
    - The final result should have the same number of significant figures as the original number with the **least** number of significant figures.
    - *Example:* Density = Mass / Volume. If Mass = 4.237 g (4 sig figs) and Volume = 2.51 $cm^3$ (3 sig figs), the result should be rounded to 3 significant figures.
        - $Density = \frac{4.237~g}{2.51~cm^3} = 1.688047...~g/cm^3 \approx \textbf{1.69~g/cm^3}$.
- **Rule 2: Addition or Subtraction**
    - The final result should retain as many **decimal places** as there are in the number with the **least** number of decimal places.
    - *Example 1:* Sum of 436.32 g, 227.2 g, and 0.301 g.
        - 227.2 g has the least decimal places (1 decimal place).
        - Sum = 663.821 g $\approx \textbf{663.8~g}$.
    - *Example 2:* Difference: 0.307 m - 0.304 m = 0.003 m. Both numbers have 3 decimal places, so the answer also has 3 decimal places (even though it only has one significant figure).
    - *Important Distinction:* The rule for addition/subtraction focuses on decimal places, not total significant figures.
